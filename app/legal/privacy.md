# AICE 개인정보처리방침

- 시행일: 2026-08-16
- 버전: 1.0

가천대학교 AICE 팀(이하 "회사")은 개인정보보호법 제30조에 따라 정보주체의 개인정보를
보호하고 이와 관련한 고충을 신속하게 처리하기 위하여 다음과 같이 개인정보처리방침을
수립·공개합니다.

---

## 1. 수집하는 개인정보 항목과 수집 방법

### 1-1. 회원가입 시 (필수)

| 가입 경로 | 수집 항목 |
|---|---|
| 이메일 가입 | 이메일 주소, 비밀번호(암호화 저장), 닉네임 |
| 구글 계정 로그인 | 구글 계정 이메일 주소, 구글 계정 식별자, 닉네임 |

### 1-2. 서비스 이용 과정에서 수집 (선택)

| 구분 | 수집 항목 |
|---|---|
| 프로필 | OpenReview 계정 ID |
| 온보딩 설문 | 이용자 유형, 연구 경력, 이용 목적, 연구 분야, 논문 진행 단계, 목표 학회, 결과 정렬 선호 |
| 업로드 자료 | 논문 PDF 파일 원본, 논문 제목, 초록, 연구 분야, 페이지 수 |
| 분석 결과 | 업로드 자료를 기준으로 생성된 유사 논문 목록, 지적사항 열람 결과, 요약 리포트 |

> 온보딩 설문은 회원가입 전 익명으로 저장했다가 가입 시 계정에 연결될 수 있습니다.
> 가입하지 않으면 해당 응답은 어떤 계정과도 연결되지 않습니다.

### 1-3. 자동으로 생성·수집되는 정보

- 접속 IP 주소 (비정상적인 접근 차단 및 요청 빈도 제한 목적)
- 서비스 이용 기록, 가입·수정 일시

### 1-4. 수집 방법

- 회원가입, 프로필 수정, 온보딩 설문, 논문 업로드 등 이용자의 직접 입력
- 서비스 이용 과정에서의 자동 생성

## 2. 개인정보의 처리 목적

회사는 수집한 개인정보를 다음 목적으로만 이용하며, 목적이 변경되는 경우 사전에
동의를 받습니다.

| 목적 | 처리하는 항목 |
|---|---|
| 회원 식별 및 인증, 로그인 유지 | 이메일, 비밀번호, 구글 계정 식별자 |
| 비밀번호 재설정 안내 메일 발송 | 이메일 주소 |
| 유사 논문 검색 및 심사 지적사항 열람 서비스 제공 | 업로드 자료(PDF, 제목, 초록, 분야) |
| 검색 결과 정렬 및 화면 구성 개인화 | 온보딩 설문 응답 |
| 부정 이용 방지, 요청 빈도 제한, 장애 대응 | 접속 IP, 이용 기록 |

**회사는 이용자의 개인정보나 업로드 자료를 인공지능 모델 학습에 사용하지 않습니다.**

## 3. 개인정보의 보유 및 이용 기간

| 구분 | 보유 기간 |
|---|---|
| 계정 정보(이메일, 비밀번호, 닉네임, 구글 식별자) | 회원 탈퇴 시까지 |
| 온보딩 설문 응답 | 회원 탈퇴 시까지 (회원가입으로 연결되지 않은 익명 응답은 30일 후 파기) |
| 업로드 PDF 원본 | 마지막 분석(분석한 적이 없으면 업로드)으로부터 90일, 또는 이용자 삭제 시까지 |
| 업로드 논문 제목·초록·분야 및 분석 결과 | 회원 탈퇴 또는 이용자 삭제 시까지 |
| 접속 IP 등 자동 수집 정보 | 1개월 |

- **회원이 탈퇴하면 위 정보는 지체 없이 파기되며, 복구할 수 없습니다.**
- 관계 법령에 따라 보존이 필요한 경우 해당 법령이 정한 기간 동안 보관합니다.

회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 근거하거나
수사기관이 적법한 절차에 따라 요구하는 경우는 예외로 합니다.

## 5. 개인정보 처리의 위탁 및 국외 이전

회사는 서비스 제공을 위해 아래와 같이 개인정보 처리를 위탁하고 있으며, 그중 일부는
국외로 이전됩니다. 개인정보보호법 제28조의8 제1항 제3호에 따라 그 내용을 아래와 같이
공개합니다.

### 5-1. Anthropic PBC — 논문 분석 (미국)

| 항목 | 내용 |
|---|---|
| 이전받는 자 | Anthropic PBC (Claude API), privacy@anthropic.com |
| 이전 국가 | 미국 |
| 이전 일시 및 방법 | 이용자가 분석을 요청한 시점에 네트워크를 통해 전송 |
| 이전 항목 | 업로드한 논문 PDF 원본 및 그로부터 추출한 제목·초록·본문 텍스트 (여기에 논문에 기재된 저자명·소속 등이 포함될 수 있습니다) |
| 이전 목적 | 논문 요약, 유사 논문 재정렬, 심사 지적사항 종합 리포트 생성 |
| 보유·이용 기간 | 처리 목적 달성 시까지. Anthropic의 상용 API 정책에 따라 최대 30일간 보관된 후 삭제됩니다. |
| 인공지능 학습 이용 여부 | **이용하지 않음.** 상용 API 약관상 전송된 입력·출력은 모델 학습에 사용되지 않습니다. |

### 5-2. 그 밖의 수탁자

| 수탁자 | 위탁 업무 | 처리 국가 |
|---|---|---|
| Amazon Web Services (EC2, RDS) | 서비스 인프라 운영 및 데이터 보관 | 대한민국 (서울 리전) |
| Amazon Web Services (SES) | 비밀번호 재설정 메일 발송 | 대한민국 (서울 리전) |
| Google LLC | 구글 계정 로그인 인증 | 미국 |

위 수탁자 중 **국외로 이전되는 것은 Google LLC(미국)뿐이며**, 나머지는 국내에서
처리됩니다. 서비스의 서버와 데이터베이스는 대한민국(AWS 서울 리전)에 있습니다.

회사는 위탁계약 시 개인정보의 안전한 관리에 관한 사항을 문서로 정하고, 수탁자가
이를 준수하는지 감독합니다.

> **이용자는 개인정보의 국외 이전을 거부할 수 있습니다.** 다만 위 이전은 서비스의
> 핵심 기능(논문 분석)에 필수적이므로, 거부하는 경우 해당 기능의 이용이 제한됩니다.

## 7. 개인정보의 파기

1. **파기 시점**: 보유 기간이 경과하거나 처리 목적이 달성된 경우 지체 없이 파기합니다.
2. **파기 방법**
   - 전자적 파일: 데이터베이스에서 삭제하여 복구할 수 없도록 처리
   - 출력물: 분쇄하거나 소각

## 8. 개인정보의 안전성 확보 조치

- **비밀번호 암호화**: 비밀번호는 복호화할 수 없는 방식(bcrypt 해시)으로 저장하며,
  회사도 원문을 알 수 없습니다.
- **전송 구간 암호화**: 이용자와 서버 간 통신은 HTTPS로 암호화합니다.
- **접근 권한 최소화**: 개인정보에 접근할 수 있는 인원을 운영에 필요한 최소한으로
  제한하고, 권한 부여·변경·말소 기록을 관리합니다.
- **부정 접근 차단**: 로그인 등 인증 관련 요청에 빈도 제한을 적용합니다.
- **인증 정보 무효화**: 로그아웃 시 기존에 발급된 인증 토큰을 모두 무효화합니다.
- **운영 로그 관리**: 서비스 운영 기록에 이용자가 업로드한 논문 본문이나 그 요약이
  남지 않도록 관리합니다.
